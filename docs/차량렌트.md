# 풀빌라 카니발 무료 렌탈 관리 시스템 기능 요구사항

## 1. 시스템 개요  
### 1.1. 목적

제주도 풀빌라(빌라1, 프리미엄) 2박 이상 예약 고객에게 제공하는 카니발 무료 차량 대여 서비스를 관리하기 위한 관리자 시스템을 구축한다.

차량 대여 일정을 시스템화하여 다음 문제를 해결하는 것을 목적으로 한다.

- 동일 차량의 중복 예약 방지
- 고객 및 운전자 정보 체계적 관리
- 차량 이용기간 확인
- 공항 차량 픽업 및 반납 일정 관리
- 픽업 기사 및 숙소 관리자에게 일정 자동 알림
- 차량별 현재/향후 예약 현황 확인
- 일정 누락 및 업무 착오 방지

## 2. 사용자
### 2.1 관리자
숙소 운영 담당자.

주요 권한:
- 차량 예약 등록
- 차량 예약 수정 및 취소
- 고객정보 등록 및 조회
- 차량 배정
- 공항 픽업/반납 일정 등록
- 차량 스케줄 확인
- 문자 발송 내역 확인
- 리마인드 설정
- 차량 관리

### 2.2 픽업 기사
공항 또는 지정 장소에서 차량을 이동시키는 담당자.

## 3. 차량 관리
### CAR-01 차량 등록
관리자는 대여 가능한 차량을 등록할 수 있어야 한다.

등록 정보:
- 차량 ID
- 차량번호
- 차종

차량 상태 예시:
- 대여 가능
- 대여 중
- 정비 중
- 사용 중지

### CAR-02 차량 수정
관리자는 차량 정보를 수정할 수 있어야 한다.

### CAR-03 차량 사용 중지
특정 차량을 일정 기간 예약할 수 없도록 설정할 수 있어야 한다.

예:
- 차량 정비
- 사고
- 검사
- 내부 사용
사용 중지 기간에는 신규 예약을 등록할 수 없어야 한다.

## 5. 차량 예약 관리
### RESERVATION-01 차량 예약 등록

관리자는 고객에게 확인한 차량 사용기간을 기준으로 차량 예약을 등록할 수 있어야 한다.

등록 정보:
- 고객
- 운전자
- 차량
- 차량 이용 시작일시
- 차량 이용 종료일시
- 이용객실
- 숙소 체크인/체크아웃 날짜
- 차량 전달 방식
- 차량 반납 방식
- 운전면허 확인 여부
- 메모

### RESERVATION-02 차량 예약 상태
예약은 상태 값을 가져야 한다.

예:
- 이용 완료
- 취소

### RESERVATION-04 예약 충돌 표시
관리자가 예약을 입력하면서 차량과 사용기간을 지정하면 즉시 다음 내용을 보여준다.

- 예약 가능
- 기존 예약과 충돌
- 차량 정비 기간과 충돌

충돌하는 경우 기존 예약 고객과 시간을 보여준다.

예:  
예약 불가  
9/10 10:00 ~ 9/12 18:00  
김OO 고객 예약이 존재합니다.
